# v2 build status — News Fact-Checker & Polarization Analyzer

Built 2026-09-09, on top of the v1 scaffold. Terminal-only (web UI is v3).

## What v2 delivers

- **All five agents present and communicating** through the shared SQLite
  blackboard (no direct hand-offs):
  Source-Finder ∥ Opposition → Cross-Checker → Bias/Blindspot Analyzer → Writer,
  with a bounded deep-research loop back to Cross-Checker on low-confidence
  `disputed` verdicts.
- **The whole run is visible in the terminal** — a `rich` live dashboard shows,
  per news item: the five agents and their status, the current contents of the
  shared blackboard, and a streaming log of every agent ↔ blackboard event and
  tool call. Each finished item prints a rendered report; the run ends with a
  recap table.
- **Append-only `audit_log`** table backs the dashboard and gives the audit
  trail the resource doc calls for.
- **Runs with env still stubbed:** `python -m newsfact.main --demo` runs the
  entire pipeline + dashboard offline using scripted GDELT/Claude fixtures.
  Three bundled sample claims exercise the corroborated / disputed-with-loop /
  unverifiable paths. Set `ANTHROPIC_API_KEY` to switch to the real clients.

## Run it

```bash
cd news-fact-checker
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
python -m newsfact.main --demo            # live dashboard
python -m newsfact.main --demo --plain    # flat trace (pipe-friendly)
pytest                                    # 44 tests, all offline
```

## Verified this session

- 44 unit/integration tests pass, fully offline (no API keys, no network).
- `--demo` run produces all three verdict paths and fires the deep-research
