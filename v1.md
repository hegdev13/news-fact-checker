# v1 build status — News Fact-Checker & Polarization Analyzer

Built 2026-09-09. Delivered to the user as `news-fact-checker.zip` (a git repo with one commit).

## Stack decided
- Python 3.11+, LangGraph for orchestration, Anthropic Claude for LLM reasoning,
  GDELT DOC 2.0 API for news search (no key needed), SQLite for shared memory.
- Full rationale in the repo's `docs/ARCHITECTURE.md`.

## What v1 implements
Two agents sharing a SQLite blackboard store, orchestrated as a linear LangGraph:
- **Source-Finder** — queries GDELT for a claim, writes findings to the shared store.
- **Cross-Checker** — reads findings, asks Claude to assess agreement/conflict across
  independent outlets, writes a confidence-scored verdict (label constrained to
  `corroborated` / `disputed` / `unverifiable` — never binary true/false).

Not built yet: Opposition agent, Bias/Blindspot Analyzer, Writer, Indian-outlet
bias table, deep-research loop on conflict, formal audit log, story clustering.
Full priority-ordered list is in the repo's `docs/HANDOFF.md`.
